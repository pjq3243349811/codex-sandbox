# 每天一点 · 学习陪练站

纯静态中文站点，无构建步骤、无第三方依赖、无账号及付费服务。所有资源使用相对路径。

## 打开方式

在仓库根目录执行：

```sh
python3 -m http.server 8000
```

浏览器访问 http://localhost:8000/study/ 。不要直接双击 HTML（file:// 下浏览器通常禁止读取 JSON）。

GitHub Pages 配置为部署包含本目录的分支、根目录 `/` 后，访问：
https://pjq3243349811.github.io/codex-sandbox/study/

若仓库已有 Pages 工作流，需确认该工作流发布仓库根目录及 `study/`。本任务不修改 Pages 设置及工作流。

## 文件和数据

- `index.html`：页面结构与复习对话框。
- `styles.css`：圆角柔和布局及移动端适配。
- `app.js`：课程渲染、筛选、进度、继续学习和随机复习。
- `exercises.json`：60 天课程。模块天数依次为 14、10、6、14、8、8。WPS 表格提供完整练习步骤、成品、验收清单、复习问题；其余模块为标题与成品提纲，界面明确标注详细步骤待补充。

每课 `id` 是打卡关联键，后续补充内容请保持不变。`day` 为全路线天数；`minutes` 为练习预算；`steps`、`product`、`checklist`、`question` 对应课程卡和复习。`detailed` 控制详细课/提纲标记。

打卡存于当前来源下 localStorage 的 `daily-study-progress-v1`，值为课程 ID 到 ISO 打卡时间的映射。没有服务端同步；更换设备、浏览器、域名或清除网站数据不会保留进度。存储受限时页面提示仅本次有效。成品由学习者自行保存，不上传到网站。PS/Illustrator 练习假定已有合法可用软件，可使用现有免费工具练习对应技能；网站不引导购买软件。

## 手工验证

1. 默认看到 WPS 表格 14 天，逐课展开检查步骤、成品和清单。
2. 打卡一课：总进度为 1/60，模块为 1/14，刷新仍保留；撤销后恢复。
3. 切换模块，确认 10/6/14/8/8 天课程及提纲标记；用全部、未完成、已完成筛选。
4. 无打卡时随机抽题显示空态；有打卡后只抽已完成课程的问题，参考来自该课验收清单。
5. 点击继续练习定位最早未完成课程；完成全部课程后引导复习。
6. 在 375px 手机宽度和桌面检查无横向溢出；用键盘操作按钮、课程折叠、对话框，Escape 可关闭复习。
