# 抖音选题工作台

AI 工具教程创作者的纯静态工具，无依赖、无构建、无付费服务。

## 打开

- 直接用浏览器打开 `douyin-topics/index.html`。
- 推荐从仓库根目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/douyin-topics/`。
- GitHub Pages：仓库 Settings → Pages 选择包含本次提交的分支、`/ (root)`，部署后访问 `https://pjq3243349811.github.io/codex-sandbox/douyin-topics/`。已有 Pages 配置可继续沿用，不需要修改根目录首页。

## 使用与验证

1. 新建选题，填写标题、3 秒钩子、脚本、素材链接、状态和标签。标签用中英文逗号分隔，链接每行一个，只接受 HTTP/HTTPS。
2. 编辑时点击「填入脚本模板」，把录屏配音模板放入大纲；替换已有脚本需确认。保存后展开卡片查看脚本和链接。
3. 编辑或删除卡片；组合使用状态和标签筛选、关键词搜索。搜索覆盖标题、钩子、大纲、标签、素材链接。
4. 灵感箱随手记，刷新后保留。「转为选题」保存成功后才移除原灵感，取消不会丢失。
5. 导出、再导入 JSON：包含全部选题与灵感；先校验格式、字段、ID、链接及文件大小，再确认合并。相同 ID 保留当前版本，重复导入不会产生重复记录。备份用于合并恢复，如要回退某张卡片，请手动编辑。
6. 手机宽度下验证无横向滚动、编辑框可滚动、按钮可点击；支持 Tab 导航和 Escape 关闭编辑框。

数据保存在当前浏览器 localStorage 的独立键 `douyin-topics.v1`，不上传、不跨设备同步。不同域名、端口或浏览器的数据独立；直接 file 打开的存储行为取决于浏览器。清理站点数据会删除记录，请定期导出备份。保存失败会提示并保留编辑框内容。

备份格式：`{"version":1,"topics":[{"id":"唯一ID","title":"标题","hook":"钩子","outline":"大纲","links":[],"status":"待拍","tags":[]}],"ideas":[{"id":"另一个ID","text":"灵感"}]}`。

仅新增本目录文件，不涉及根目录首页、weather.json 或天气数据管线。
