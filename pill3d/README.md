# PILL 结构实验室

入口：`pill3d/index.html`。纯静态 Three.js 单页，GitHub Pages 直接访问 `/codex-sandbox/pill3d/`，无构建、账户或付费服务。Three.js 0.170.0 与 OrbitControls 本地保存，许可证位于 vendor/LICENSE；不依赖第三方 CDN 运行。

本地运行：仓库根目录执行 `python3 -m http.server 8000`，打开 `http://localhost:8000/pill3d/`。ES Modules 需要 HTTP 服务，不使用 file://。

两组模型保持左右并排，手机亦可独立单指旋转、双指缩放；两条滑杆独立控制分解程度。点击零件或目录按钮显示名称、作用并高亮，目录支持键盘操作。重置按钮恢复视角，组装和分解按钮分别设为 0% 与 100%。

## 依据及边界

- [水月雨官方产品页](https://moondroplab.com/cn/products/pill)：产品外观、型号 MD-OWS-003、蓝牙 6.0、40mAh/300mAh、13mm 单元及 C 桥材质。
- [我爱音频网拆解报告](https://www.52audio.com/archives/278516.html)，2026-06-05：[同源搜狐转载](https://www.sohu.com/a/1032440529_100193168)。原站图片访问返回 403，使用同源转载的拆解图片参考（外观图 6、前音腔图 13、仓体图 27、主板图 50）。官方产品图可从官网商品详情查看。
- 充电仓：IP5516、ST 702027 3.7V/300mAh、Type-C 输入小板、Pogo pin、磁铁、旋转座舱与胶囊壳。
- 耳机：BT8932F、ST 501012 3.7V/40mAh、13mm 动圈、敏芯 MG52 MEMS、陶瓷蓝牙天线、顺络陶瓷电感、导电布、外壳与 TPU/钛合金 C 桥。
- 报告末尾总结误写耳机 300mAh；以正文 ST 501012 电池特写段和官方一致的 40mAh 为准。

程序化模型为结构学习示意，非扫描、CAD 或官方工程模型。曲面、布局距离、配色、封装比例均简化；微小元件放大以便点选，分解方向为展示安排，不作维修指引。省略未展示的外围电路、胶水、螺丝与走线，并未将它们假定为不存在。芯片以独立层分离是展示处理，不表示插拔安装。
